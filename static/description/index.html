Odoo Branding & Navbar Customizer

A modern, multi-company branding extension that seamlessly positions your company logo on the top-left navigation bar and gives you complete real-time control over navbar colors and theming.

✨ Key Features

🏢

Top-Left Company Logo

Displays your company branding logo directly on the far left of the navbar before any app icons. Includes customizable display height and clickable home menu toggle.

🎨

Interactive UI Color Pickers

Customize Background, Text, Active Highlights, and Hover colors using native color pickers right inside Odoo Settings.

🌓

Dark & Light Mode Perfect

Engineered with transparent container overlays so that text and icons retain perfect high-contrast visibility regardless of whether dark or light mode is selected.

⚡

Zero Server Restarts

Changes to branding and colors apply in real-time across users without rebuilding assets bundles or restarting the Odoo server.

🌐

Multi-Company Support

Each company in a multi-company environment can have its own distinct branding logo, title, and color scheme.

🏷️

Custom System Title

Optionally set a custom brand or system title for browser tabs and window headers.

📖 How It Works

  1. Go to Settings > General Settings > Odoo Branding (or directly edit your company in Settings > Users & Companies > Companies).
  2. Upload Navbar Logo: Upload a PNG/SVG logo designed for navbar display (if left empty, your main company logo is used automatically).
  3. Pick Theme Colors: Choose your Background, Text, Active, and Hover colors using the intuitive color pickers.
  4. Adjust Dimensions: Set the exact logo height in pixels (e.g. 28px - 36px) and choose whether to display the company name text.
  5. Click Save — your navigation bar branding updates instantly!
